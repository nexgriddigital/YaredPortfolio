Yared Teumelisan - portfolio website

OPEN IT: double-click index.html (works offline; the headings use Google Fonts when online).
PUT IT ONLINE: upload this whole folder to any static host (Netlify Drop, GitHub Pages, Cloudflare Pages, or normal web hosting). index.html must stay at the top level next to the images folder.

index.html   the website (design, intro animation, image viewer)
images/      his 29 portfolio pages in original order (page-01 is the CV)
favicon.png / favicon.ico   browser tab icon made from his logo
assets/      logo as SVG and PNG

To change the contact details, search index.html for "yaredteumelisan@gmail.com".
To replace a page, overwrite its file in images/ with a JPG of the same name.
